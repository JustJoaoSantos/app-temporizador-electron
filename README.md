# Overview
- Um simples projeto criado com o intuito de se familializar com 
as ferramentas web, como: react, electron, node.js, etc.

- O projeto iniciou-se ao perceber uma certa inconveniencia em 
marcar o horario para inicio de uma reuniao, o requito seria
um app simples e leve, com o unico intuito de marcar e mostrar
uma contagem regresiva para o inicio da reuniao.
